# al.code-design

Site web officiel de **al.code-design** — Agence web locale spécialisée dans la création de sites pour commerces et PME (boulangeries, garages, salons, restaurants, boutiques, etc.).

🌐 **Site en ligne** : https://al-code-design.github.io/

## 🛠 Stack technique

- HTML5, CSS3 (vanilla, pas de framework)
- JavaScript vanilla (ES6+)
- [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) + [Fraunces](https://fonts.google.com/specimen/Fraunces) via Google Fonts
- [EmailJS](https://www.emailjs.com/) pour l'envoi des formulaires (sans backend)
- Hébergé sur GitHub Pages

## 📁 Structure

```
.
├── index.html              # Page principale
├── mentions-legales.html   # Mentions légales + RGPD
├── robots.txt              # Indexation Google
├── sitemap.xml             # Plan du site
├── .nojekyll               # Désactive Jekyll sur GitHub Pages
└── README.md               # Ce fichier
```

## 🚀 Déploiement

1. Push sur la branche `main`
2. GitHub Pages déploie automatiquement
3. Le site est accessible sous 1-2 minutes sur l'URL canonique
